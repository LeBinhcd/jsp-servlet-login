# JSP Servlet Login - Complete Submission

This repository contains both the standard Maven project and a flat `submission/` folder for automated graders.

## Standard project files

- `pom.xml`
- `src/main/java/com/codegym/LoginServlet.java`
- `src/main/webapp/index.jsp`
- `src/main/webapp/WEB-INF/web.xml`

## Flat submission files

- `submission/pom.xml`
- `submission/LoginServlet.java`
- `submission/index.jsp`
- `submission/web.xml`

The application uses Jakarta Servlet 6.0, Java 17, and Tomcat 10.1+. Build it with `mvn clean package`.
