# Submission note

The complete Maven project is in the repository root and uses the standard Maven Webapp structure:

- `pom.xml`
- `src/main/java/com/codegym/LoginServlet.java`
- `src/main/webapp/index.jsp`
- `src/main/webapp/WEB-INF/web.xml`

For graders that only inspect a flat submission folder, the same required files are also provided directly in this `submission/` folder:

- `submission/pom.xml`
- `submission/LoginServlet.java`
- `submission/index.jsp`
- `submission/web.xml`

The files in `submission/` are copies of the working project files and are included only to make every required deliverable visible to automated evaluation.
